# Recorrido de Figma sin inventar el diseño del Switch

El facilitador confirmó que no tiene el enlace al nodo del Switch. No solicitarlo de nuevo.

Caso documental de la cohorte: PR #7, https://github.com/LIDR-academy/AI4Devs-frontend-202606-senior-2/pull/7.

Diseño citado por el autor: https://www.figma.com/design/cfFXOqhi8z4mqlhXrYA5I9/?node-id=1-1989 (Simple Kanban, no Switch).

Recorrido de 5 minutos: localizar el nodo citado; inspeccionar frontend/src/theme/figma-export.json; seguir frontend/scripts/figma-to-tokens.mjs; localizar un token semántico en CandidateCard y discutir la ampliación Bootstrap → Chakra. El archivo exportado del PR es evidencia disponible aunque Figma no abra; no afirmar que se volvió a consultar el MCP si no ocurrió.

Para el componente nuevo de la práctica, describir primero el contrato escrito: interruptor de notificaciones con checked, onCheckedChange y disabled. Enseñar la skill de Figma como flujo reutilizable; su ejecución en vivo depende de MCP/acceso configurados. Separar el diseño del kanban de los estados del Switch.
